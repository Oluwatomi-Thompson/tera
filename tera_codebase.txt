## ADR-003: Collapse the `quizzes` table into `questions`
- Context: The original ERD had `quizzes {id, lesson_id}` purely as a join
  table with no attributes of its own â€” every query about a lesson's quiz
  had to join through it for nothing.
- Decision: Removed `quizzes`. `questions.lesson_id` now points directly at
  `lessons.id`. A lesson's questions are implicitly "its quiz."
- Consequences: One fewer table, model, and migration to maintain. If a
  future requirement needs multiple quizzes per lesson or per-quiz settings
  (time limits, retakes), reintroduce `quizzes` then â€” it's a cheap
  Alembic migration, not worth paying for now.

## ADR-004: Markdown files are the single source of truth for lesson content
- Context: Content accuracy (RWF figures, institution names, thresholds) is
  the core risk for this product. Editing `lessons.content_body` directly
  through an admin panel would create two writable copies of the same
  content (the `.md` file and the DB row) that can silently drift â€”
  especially risky here because every factual claim needs to stay traceable
  to a citation.
- Decision: `app/content/lessons/*.md` is authoritative. `flask seed-db`
  (see app/commands.py) parses each file's YAML frontmatter + body and
  upserts the matching `Lesson`/`Question`/`Choice` rows by `slug`. The
  admin panel (FR10) does NOT provide a content_body edit form; it only
  manages what has no natural home in a `.md` file: publish/unpublish
  (`is_published`), reordering, and triggering a resync. Content authoring
  happens in a text editor, with real git history and diffs for every
  factual change.
- Consequences: FR10 in the SRS reads as "admin content management," which
  now means something narrower than full CRUD â€” worth a one-line note if a
  facilitator asks why there's no lesson-edit form in the admin UI. Tradeoff
  accepted deliberately: one source of truth was a stated priority over
  admin-panel completeness.

@bp.post("/lessons/<int:lesson_id>/reorder/<direction>")
@login_required
@admin_required
def reorder_lesson(lesson_id, direction):
    """Swap this lesson's order_index with its neighbor's â€” keeps
    order_index unique at all times (the DB constraint requires it) instead
    of renumbering the whole list on every move."""
    if direction not in ("up", "down"):
        flash("Invalid reorder direction.", "error")
        return redirect(url_for("admin.dashboard"))

    lesson = Lesson.query.get_or_404(lesson_id)
    neighbor_query = Lesson.query.filter(
        Lesson.order_index < lesson.order_index
        if direction == "up"
        else Lesson.order_index > lesson.order_index
    ).order_by(Lesson.order_index.desc() if direction == "up" else Lesson.order_index.asc())
    neighbor = neighbor_query.first()

    if neighbor is None:
        flash(f"'{lesson.title}' is already at the {'top' if direction == 'up' else 'bottom'}.", "info")
        return redirect(url_for("admin.dashboard"))

    # order_index is UNIQUE and SQLite enforces that immediately (not
    # deferred), so writing both new values in one flush can collide with
    # whatever value is still on the *other* row at the instant either
    # single UPDATE executes. Route one side through a temporary value
    # that can't collide with anything, flushing between steps, then land
    # both rows on their final values in a last flush.
    lesson_target, neighbor_target = neighbor.order_index, lesson.order_index
    lesson.order_index = -1
    db.session.flush()
    neighbor.order_index = neighbor_target
    db.session.flush()
    lesson.order_index = lesson_target
    db.session.commit()
    return redirect(url_for("admin.dashboard"))

"""
Request/response shapes for the API blueprint. Kept as plain functions
rather than a schema library (Marshmallow etc.) â€” the surface area here is
one endpoint, so a dependency for validation would be heavier than the
problem.

POST /api/v1/calculator
  Request JSON:  {"monthly_rwf": int, "months": int, "annual_rate": float?}
  Response JSON: {"schedule": [{"month": int, "balance": int}, ...],
                   "total_contributed": int, "total_value": int,
                   "growth": int, "annual_rate": float, "months": int,
                   "monthly_rwf": int}
  Errors: 400 {"error": "..."} for bad/missing input.
"""


def parse_calculator_request(payload: dict) -> tuple[int, int, float]:
    if not isinstance(payload, dict):
        raise ValueError("Request body must be a JSON object.")

    try:
        monthly_rwf = int(payload.get("monthly_rwf", 2000))
        months = int(payload.get("months", 24))
    except (TypeError, ValueError):
        raise ValueError("monthly_rwf and months must be numbers.")

    annual_rate = payload.get("annual_rate", 0.10)
    try:
        annual_rate = float(annual_rate)
    except (TypeError, ValueError):
        raise ValueError("annual_rate must be a number.")

    if monthly_rwf < 0 or monthly_rwf > 10_000_000:
        raise ValueError("monthly_rwf must be between 0 and 10,000,000.")
    if months < 1 or months > 480:
        raise ValueError("months must be between 1 and 480.")
    if annual_rate < 0 or annual_rate > 1:
        raise ValueError("annual_rate must be between 0 and 1 (e.g. 0.10 for 10%).")

    return monthly_rwf, months, annual_rate

## Content

Here's the assumption this whole course is built to correct: that investing
requires a large amount of money you don't currently have. For Rwanda
specifically, that's not true.

**RNIT's Iterambere Fund** has a reinvestment-option minimum of just **RWF
2,000**, with additional contributions accepted in multiples of RWF 1,000
after that (RNIT, 2024). That's less than many people spend on mobile data
or transport in a single week. This is the single lowest, most concrete
entry point referenced throughout this course.

**Rwanda Stock Exchange shares** work differently â€” you buy in board lots
of a minimum of 100 shares (EFG Hermes, 2025), so your actual minimum cost
depends on that day's share price for whichever company you're interested
in. Share prices move, so this course won't quote you a fixed total â€” check
current prices directly with the RSE or a licensed broker when you're ready.

**The real barrier usually isn't the minimum amount â€” it's not knowing the
minimum amount exists.** That's the information gap Tera was built to
close: most people researching "how to invest" encounter guides built
around foreign minimums and foreign currencies, never see a number like
"RWF 2,000," and reasonably conclude investing isn't for them yet.

**What small, regular contributions can become over time** is exactly what
Tera's [calculator](/lessons/calculator) is for â€” try putting in a monthly
amount you could realistically set aside, and see a rough, illustrative
projection of how it could grow. It's not a guarantee from any institution,
just a way to make the idea concrete.

Once you've gone through these five lessons, you have what you need to go
talk to a real institution. That's the whole plan.

Most investing guides are written assuming you already have a bank account
and a credit card. In Rwanda, that's backwards: mobile money reaches far

survey, about 86% of adults use mobile money, while only around 22% are

## Content

Every investment carries some risk â€” the possibility that it's worth less
when you sell than when you bought it. In exchange for accepting that risk,
investors generally expect a higher potential return than they'd get from
simply saving. This is the central trade-off in investing: more potential
growth generally comes with more potential for loss. Understanding it is
the whole point of this lesson.

**Different instruments carry different risk levels.** Broadly, government
bonds are considered lower-risk (the government is a relatively reliable
borrower), individual company shares are higher-risk (a single company's
value can swing a lot), and a diversified fund sits in between â€” because it
spreads your money across many assets instead of betting on one. RNIT's
Iterambere Fund, for example, is structured with "exposure to debt assets
including money market instruments up to 100%, while having the objective
to invest in equity assets up to 30%" (RNIT, 2024) â€” a deliberate mix meant
to balance safety and growth rather than maximize either one alone.

**Diversification** is the practice of not putting all your money in one
place. A fund that holds many different bonds and shares is less exposed to
any single company or sector doing badly. This is part of why Rwanda's
capital market institutions have specifically promoted collective investment
schemes (unit trusts) as an accessible starting point for new investors â€”
they offer diversification without requiring you to personally research and
pick individual company shares.

**Time horizon matters too.** Money you might need next month shouldn't be
invested in anything volatile â€” that's what savings and emergency funds are
for. Money you won't need for several years has more room to ride out
short-term ups and downs. Rwanda's Capital Markets Authority has
specifically framed the capital market as "a tool for building long-term
financial independence" (CMA, 2025) â€” not a place for money you need back
tomorrow.

**What this lesson is not:** a recommendation to buy any specific product.
Tera doesn't tell you what to invest in â€” that decision, and its risk, is
yours to make with a licensed institution directly.

## Content

This is the lesson where the names stop being abstract. Here are the real
institutions behind Rwanda's capital market â€” the same ones Tera's
[resource directory](/institutions/) links to directly.

**Capital Markets Authority (CMA)** â€” the regulator. The CMA doesn't sell
you anything; it licenses and oversees everyone else on this list, and runs
public education initiatives specifically aimed at closing the investment
literacy gap this course exists to address (CMA, 2025). If you want to
confirm whether a broker or fund is actually licensed, the CMA is the
authority to check with.

**Rwanda Stock Exchange (RSE)** â€” where shares of publicly listed companies
(banks, telecoms, manufacturers, and others) are bought and sold. You don't
trade directly on the RSE yourself; you go through a licensed brokerage
firm. Shares trade in board lots with a minimum of 100 shares per
transaction (EFG Hermes, 2025) â€” so your entry cost depends on the price of
the particular share, which changes daily like any market.

**Rwanda National Investment Trust (RNIT)** â€” a government-owned fund
manager running the Iterambere Fund, a unit trust (a professionally managed,
diversified pool of investments) designed specifically to be accessible:
its minimum initial investment under the reinvestment option is just RWF
2,000, "in multiples of '000 thereafter" (RNIT, 2024). This is the lowest
realistic entry point covered in this course, and the specific figure
referenced in Tera's own problem statement.

**Licensed brokers** â€” firms authorized by the CMA to execute trades on the
RSE on your behalf. You'll need to open an account with one if you want to
buy individual company shares rather than a pooled fund like RNIT's.

The common thread: none of these is Tera. Once you understand the basics,
the next concrete step is to visit one of these institutions directly,
confirm their current requirements, and open an account there â€” not here.

def calculate_progress(user) -> dict:

def grade_quiz(lesson, submitted_answers: dict[str, str]) -> dict:
    """Grade a quiz submission.

    `submitted_answers` maps str(question_id) -> str(choice_id), the shape
    Flask's `request.form` naturally gives us for fields named
    `question-<id>`.

    Returns {"correct_count", "total_questions", "results": [...]} where each
    result row carries enough for the template to show right/wrong + the
    correct answer without a second query.
    """
    results = []
    correct_count = 0

    for question in lesson.questions:
        selected_id = submitted_answers.get(str(question.id))
        correct_choice = next((c for c in question.choices if c.is_correct), None)
        is_correct = bool(selected_id) and selected_id.isdigit() and int(selected_id) == (
            correct_choice.id if correct_choice else None
        )
        if is_correct:
            correct_count += 1

        results.append(
            {
                "question": question,
                "selected_choice_id": int(selected_id) if selected_id and selected_id.isdigit() else None,
                "correct_choice_id": correct_choice.id if correct_choice else None,
                "is_correct": is_correct,
            }
        )

    return {
        "correct_count": correct_count,
        "total_questions": len(lesson.questions),
        "results": results,
    }


def project_compound_growth(
    monthly_rwf: float, months: int, annual_rate: float = 0.10
) -> dict:
    """What could `monthly_rwf` contributed every month become? (FR8)

    Simple monthly-compounding model: interest accrues on the running
    balance each month, then that month's contribution is added. This is an
    illustrative projection, not a guaranteed return â€” the template must
    make that caveat visible next to the number (NFR3/safety requirement in
    the SRS), since nothing here is an actual investment product.
    """
    monthly_rate = annual_rate / 12
    balance = 0.0
    schedule = []

    for month in range(1, months + 1):
        balance = balance * (1 + monthly_rate) + monthly_rwf
        schedule.append({"month": month, "balance": round(balance)})

    total_contributed = monthly_rwf * months
    total_value = round(balance)

    return {
        "schedule": schedule,
        "total_contributed": round(total_contributed),
        "total_value": total_value,
        "growth": total_value - round(total_contributed),
        "annual_rate": annual_rate,
        "months": months,
        "monthly_rwf": monthly_rwf,
    }

// Progressive enhancement for /lessons/calculator: updates the numbers and
// bar chart live as the sliders move, via the JSON API blueprint, instead
// of a full page reload on every drag. Works without JS too (the <form>
// submits as a GET and the server renders the same numbers) â€” this file
// never introduces a feature the server-rendered page lacks.

(function () {
  const form = document.getElementById("calc-form");
  if (!form) return;

  const monthlyInput = document.getElementById("monthly_rwf");
  const monthsInput = document.getElementById("months");
  const monthlyLabel = document.getElementById("monthly_rwf-value");
  const monthsLabel = document.getElementById("months-value");
  const totalContributedEl = document.getElementById("total_contributed");
  const growthEl = document.getElementById("growth");
  const totalValueEl = document.getElementById("total_value");
  const chart = document.getElementById("chart");

  const rwf = (n) => "RWF " + Math.round(n).toLocaleString("en-US");

  let debounceTimer = null;

  function recalculate() {
    const monthly_rwf = Number(monthlyInput.value);
    const months = Number(monthsInput.value);

    monthlyLabel.textContent = rwf(monthly_rwf);
    monthsLabel.textContent = `${months} months (~${(months / 12).toFixed(1)} yrs)`;

    clearTimeout(debounceTimer);
    debounceTimer = setTimeout(async () => {
      try {
        const res = await fetch("/api/v1/calculator", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ monthly_rwf, months }),
        });
        if (!res.ok) return; // fall back silently â€” the form still works via GET submit
        const data = await res.json();

        totalContributedEl.textContent = rwf(data.total_contributed);
        growthEl.textContent = "+" + rwf(data.growth);
        totalValueEl.textContent = rwf(data.total_value);

        renderChart(data.schedule);
      } catch (err) {
        // Network hiccup â€” the sliders still reflect the new values, and a
        // normal form submit (or next successful fetch) will catch up.
      }
    }, 150);
  }

  function renderChart(schedule) {
    if (!schedule.length) return;
    const maxBalance = schedule[schedule.length - 1].balance || 1;
    const step = Math.max(1, Math.floor(schedule.length / 24));

    chart.innerHTML = "";
    schedule.forEach((point, i) => {
      if (i % step !== 0 && i !== schedule.length - 1) return;
      const bar = document.createElement("div");
      bar.className = "flex-1 bg-navy-400 rounded-t";
      bar.style.height = `${Math.round((point.balance / maxBalance) * 1000) / 10}%`;
      bar.title = `Month ${point.month}: ${rwf(point.balance)}`;
      chart.appendChild(bar);
    });
  }

  monthlyInput.addEventListener("input", recalculate);
  monthsInput.addEventListener("input", recalculate);
})();

"""
CLI commands, plus the seeding/sync-check logic the admin panel reuses.

`flask seed-db` (and the admin "Resync" button, which calls the same
`seed_all()`) make app/content/lessons/*.md the single source of truth for
lesson + quiz content. Upserts by `slug`, so re-running it after editing a
.md file updates the matching DB row instead of creating a duplicate. The
admin panel is NOT expected to edit content_body directly â€” see
ai-context/08-decisions.md (ADR-004) for why, and app/admin/routes.py for
what the admin panel does instead.
"""
from __future__ import annotations

import re
from pathlib import Path

import click
import yaml
from flask.cli import with_appcontext

CONTENT_DIR = Path(__file__).parent / "content" / "lessons"

QUESTION_RE = re.compile(r"^\d+\.\s+(?P<question>.+)$")
CHOICE_RE = re.compile(r"^\s*-\s*\[(?P<mark>[ xX])\]\s*(?P<choice>.+)$")


def _parse_lesson_file(path: Path) -> tuple[dict, str, list[dict]]:
    """
    Returns (frontmatter_dict, content_markdown, questions) where questions is
    [{"text": ..., "order_index": ..., "choices": [{"text": ..., "is_correct": bool}, ...]}]

    Expects the format in app/content/lessons/_TEMPLATE.md:
    ---
    slug: what-is-investing
    order: 1
    title: "..."
    is_published: false
    objective: "..."
    sources:
      - "..."
    ---
    ## Content
    ...
    ## Quiz
    1. Question?
       - [ ] wrong
       - [x] right
    """
    raw = path.read_text(encoding="utf-8")
    if not raw.startswith("---"):
        raise ValueError(f"{path.name}: missing YAML frontmatter (must start with '---')")

    _, fm_raw, body = raw.split("---", 2)
    meta = yaml.safe_load(fm_raw) or {}

    for required in ("slug", "order", "title"):
        if required not in meta:
            raise ValueError(f"{path.name}: frontmatter missing required field '{required}'")

    content_match = re.search(r"##\s*Content\s*\n(.*?)(?=\n##\s*Quiz|\Z)", body, re.S)
    quiz_match = re.search(r"##\s*Quiz\s*\n(.*)", body, re.S)

    content_md = content_match.group(1).strip() if content_match else body.strip()
    questions: list[dict] = []

    if quiz_match:
        current = None
        order_index = 0
        for line in quiz_match.group(1).splitlines():
            q = QUESTION_RE.match(line)
            c = CHOICE_RE.match(line)
            if q:
                order_index += 1
                current = {"text": q.group("question").strip(), "order_index": order_index, "choices": []}
                questions.append(current)
            elif c and current is not None:
                current["choices"].append(
                    {
                        "text": c.group("choice").strip(),
                        "is_correct": c.group("mark").lower() == "x",
                    }
                )

    return meta, content_md, questions


def _lesson_files() -> list[Path]:
    return sorted(f for f in CONTENT_DIR.glob("*.md") if not f.name.startswith("_"))


def _lesson_differs(lesson, meta, content_md, questions) -> bool:
    """True if the DB row would change if we seeded this file right now â€”
    powers the admin "needs resync" indicator without duplicating a hash
    column that could itself go stale."""
    if lesson is None:
        return True
    if lesson.title != meta["title"]:
        return True
    if lesson.order_index != meta["order"]:
        return True
    if (lesson.content_body or "").strip() != content_md.strip():
        return True
    if len(lesson.questions) != len(questions):
        return True
    for existing_q, new_q in zip(lesson.questions, questions):
        if existing_q.text.strip() != new_q["text"].strip():
            return True
        if len(existing_q.choices) != len(new_q["choices"]):
            return True
        for existing_c, new_c in zip(existing_q.choices, new_q["choices"]):
            if existing_c.text.strip() != new_c["text"].strip() or existing_c.is_correct != new_c["is_correct"]:
                return True
    return False


def sync_report() -> list[dict]:
    """One row per .md file for the admin dashboard: does the DB match the
    file right now, or does someone need to hit "Resync"?"""
    from app.models import Lesson

    report = []
    for path in _lesson_files():
        try:
            meta, content_md, questions = _parse_lesson_file(path)
        except ValueError as exc:
            report.append({"path": path.name, "error": str(exc)})
            continue

        lesson = Lesson.query.filter_by(slug=meta["slug"]).first()
        report.append(
            {
                "path": path.name,
                "slug": meta["slug"],
                "title": meta["title"],
                "lesson": lesson,
                "is_stale": _lesson_differs(lesson, meta, content_md, questions),
                "question_count": len(questions),
            }
        )
    return report


def seed_all() -> int:
    """Upsert Lesson/Question/Choice rows from app/content/lessons/*.md by
    slug. Returns the number of files processed. Shared by `flask seed-db`
    and the admin panel's "Resync" button (app/admin/routes.py)."""
    from app.extensions import db
    from app.models import Choice, Lesson, Question

    files = _lesson_files()
    parsed = []  # [(lesson, meta, content_md, questions, source_path), ...]

    for path in files:
        try:
            meta, content_md, questions = _parse_lesson_file(path)
        except ValueError:
            continue  # already surfaced via sync_report()/CLI error output

        lesson = Lesson.query.filter_by(slug=meta["slug"]).first()
        if lesson is None:
            lesson = Lesson(slug=meta["slug"])
            db.session.add(lesson)
        source_path = str(path.relative_to(CONTENT_DIR.parent.parent.parent))
        parsed.append((lesson, meta, content_md, questions, source_path))

    # order_index is UNIQUE, and the admin panel's reorder control (see
    # app/admin/routes.py) can leave the DB's current values out of sync
    # with each file's `order:` frontmatter â€” e.g. an admin moved lesson A
    # above lesson B without touching their .md files. Writing the files'
    # target order_index values directly, one lesson at a time, then
    # collides with whatever the *next* lesson in the loop still holds,
    # because SQLAlchemy autoflushes the pending UPDATE as soon as the next
    # iteration's `Lesson.query.filter_by(...)` runs.
    #
    # Fix: stage every touched lesson onto a disjoint negative placeholder
    # first (can't collide with any real value or each other) and flush
    # that as its own step, then apply the real target values in a second
    # pass. Markdown stays authoritative â€” this only changes the order in
    # which writes land, not which values win.
    for i, (lesson, *_rest) in enumerate(parsed, start=1):
        lesson.order_index = -i
    db.session.flush()

    for lesson, meta, content_md, questions, source_path in parsed:
        lesson.title = meta["title"]
        lesson.order_index = meta["order"]
        lesson.content_body = content_md
        lesson.is_published = bool(meta.get("is_published", False))
        lesson.source_path = source_path

        # Replace questions/choices wholesale on every seed â€” simplest
        # correct behavior given markdown is authoritative; fine at this
        # content scale.
        lesson.questions = [
            Question(
                text=q["text"],
                order_index=q["order_index"],
                choices=[Choice(text=c["text"], is_correct=c["is_correct"]) for c in q["choices"]],
            )
            for q in questions
        ]

    db.session.commit()
    return len(parsed)


def seed_institutions() -> int:
    """Upsert Institution rows from app/content/institutions.yaml, matched
    by `name`. Institutions are NOT authored in the admin panel's Lesson
    sense â€” see ADR-004 â€” but seeding from a checked-in file still beats
    typing them into the DB by hand for the initial set; the admin CRUD
    form (app/admin/forms.py) is for day-to-day edits after that."""
    from app.extensions import db
    from app.models import Institution

    path = Path(__file__).parent / "content" / "institutions.yaml"
    if not path.exists():
        return 0

    data = yaml.safe_load(path.read_text(encoding="utf-8")) or []
    count = 0
    for row in data:
        inst = Institution.query.filter_by(name=row["name"]).first()
        if inst is None:
            inst = Institution(name=row["name"])
            db.session.add(inst)
        inst.description = row.get("description", "")
        inst.url = row["url"]
        inst.category = row.get("category")
        count += 1

    db.session.commit()
    return count

def render_markdown(text: str) -> str:
    """Jinja filter: `{{ lesson.content_body | render_markdown }}`.

    lessons.content_body stores RAW markdown (the single source of truth
    lives in app/content/lessons/*.md â€” see ai-context/08-decisions.md,

    return _markdown.markdown(text, extensions=["fenced_code", "tables"])


def admin_required(view):
    """Route decorator: 403s anyone who isn't logged in as an admin.

    Use *after* @login_required so an anonymous visitor gets redirected to
    login first (nicer UX) rather than a bare 403.
    """

    @wraps(view)
    def wrapped(*args, **kwargs):
        if not current_user.is_authenticated or not current_user.is_admin:
            abort(403)
        return view(*args, **kwargs)

    return wrapped

# Content Sync Flow

Textual sketch â€” turn this into an actual diagram alongside the ERD once
you're in your diagramming tool of choice.

```
app/content/lessons/*.md  (source of truth, git-tracked, cited facts)
        â”‚
        â”‚  flask seed-db   (app/commands.py: seed_db_command)
        â”‚  â€” parses YAML frontmatter + "## Content" / "## Quiz" sections
        â”‚  â€” upserts by `slug`
        â–¼
   lessons / questions / choices tables  (Postgres/SQLite)
        â”‚
        â”‚  read-only from here on for content_body
        â–¼
   Lesson list / detail / quiz routes  (app/lessons/)

Admin panel (app/admin/) only touches:
  - lessons.is_published
  - lessons.order_index
  - triggers a resync (same logic as `flask seed-db`, from the UI)
It never writes lessons.content_body, questions.*, or choices.* directly.
```

## Why this matters for citations
Every RWF figure or institution name in a lesson traces back to a `sources:`
entry in that lesson's `.md` frontmatter. Keeping authoring in files (not a
DB-backed rich text editor) means that trail stays intact in git history â€”
useful both for your own fact-checking discipline and if a facilitator asks
where a specific number came from.

def run_migrations_offline():
    """Run migrations in 'offline' mode.

    This configures the context with just a URL
    and not an Engine, though an Engine is acceptable
    here as well.  By skipping the Engine creation
    we don't even need a DBAPI to be available.

    Calls to context.execute() here emit the given string to the
    script output.

    """
    url = config.get_main_option("sqlalchemy.url")
    context.configure(
        url=url, target_metadata=get_metadata(), literal_binds=True
    )

    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online():
    """Run migrations in 'online' mode.

    In this scenario we need to create an Engine
    and associate a connection with the context.

    """

    # this callback is used to prevent an auto-migration from being generated
    # when there are no changes to the schema
    # reference: http://alembic.zzzcomputing.com/en/latest/cookbook.html
    def process_revision_directives(context, revision, directives):
        if getattr(config.cmd_opts, 'autogenerate', False):
            script = directives[0]
            if script.upgrade_ops.is_empty():
                directives[:] = []
                logger.info('No changes in schema detected.')

    conf_args = current_app.extensions['migrate'].configure_args
    if conf_args.get("process_revision_directives") is None:
        conf_args["process_revision_directives"] = process_revision_directives

    connectable = get_engine()

    with connectable.connect() as connection:
        context.configure(
            connection=connection,
            target_metadata=get_metadata(),
            **conf_args
        )

        with context.begin_transaction():
            context.run_migrations()
